=======================================================
HOW TO RUN THIS PROJECT (read this first)
=======================================================

Requires Python 3.13.

Step 1 - open a terminal and go into this folder:

  cd dissertation-code

Step 2 - create a virtual environment:

  python3 -m venv .venv

Step 3 - activate it:

  source .venv/bin/activate

  Your prompt will now start with (.venv)

Step 4 - install dependencies (takes 2-3 minutes):

  pip install -e ".[dev,research]"

Step 5 - run the tests (should all pass):

  python -m pytest tests/ -q

  Expected output: 16 passed

Step 6 - run the pipeline:

  python -m src.main --quick

  Takes about 2 minutes. No internet needed.

Step 7 - check the outputs were generated:

  ls results/quick/
  ls figures/quick/

  You should see CSV files in results/quick/ and PNG files in figures/quick/

=======================================================
WHAT GETS GENERATED
=======================================================

results/quick/dataset_fingerprint.json  <- SHA-256 hash proving which data was used
results/quick/metrics_aggregate.csv     <- accuracy, F1, AUC per model
results/quick/significance_tests.csv   <- paired-t and Diebold-Mariano p-values
results/quick/trading_metrics.csv      <- Sharpe ratio, drawdown per model
figures/quick/walkforward_schematic.png <- diagram of the 19-fold validation scheme
figures/quick/metrics_table.png         <- summary table of results

=======================================================
FULL SUBMISSION ARTEFACTS
=======================================================

The final 19-fold run artefacts are in:
  results/     <- all CSVs from the full run
  figures/     <- all PNGs from the full run
  models/      <- all trained model pickle files

These were generated from the frozen dataset data/spy_raw.csv.
The quick run above generates a fresh reproducible subset to verify
the pipeline works end to end on your machine.

=======================================================
NOTES
=======================================================

- Do not re-download data. Use the bundled data/spy_raw.csv.
- Use python -m pytest, not just pytest (avoids PATH issues).
- Pickle files in models/ are for reproducibility only.
  Do not load them from untrusted sources.
