=======================================================
HOW TO RUN THIS PROJECT (read this first)
=======================================================

Requires Python 3.13.

Step 1 - open a terminal and go into this folder:

  cd dissertation-code

Step 2 - create a virtual environment:

  python3 -m venv .venv

Step 3 - activate it:

  source .venv/bin/activate

  Your prompt will now start with (.venv)

Step 4 - install dependencies (takes 2-3 minutes):

  pip install -e ".[dev,research]"

Step 5 - run the tests (should all pass):

  python -m pytest tests/ -q

  Expected output: 16 passed

Step 6 - run the pipeline:

  python -m src.main --quick

  Takes about 2 minutes. No internet needed.

Step 7 - check the outputs were generated:

  ls results/quick/
  ls figures/quick/

  You should see CSV files in results/quick/ and PNG files in figures/quick/

=======================================================
QUICK PATH vs FULL PATH — WHAT IS THE DIFFERENCE
=======================================================

QUICK PATH (what the demo video shows, what you just ran above)
---------------------------------------------------------------
Command:  python -m src.main --quick
Time:     ~2 minutes
Folds:    3 representative folds out of 19 (folds 0, 2, 17)
Output:   results/quick/ and figures/quick/
Purpose:  Proves the pipeline works end-to-end on your machine.
          Generates fresh results from scratch so you can verify
          the code is real and reproducible.

The demo video shows this exact path. The results/quick/ and
figures/quick/ folders in this ZIP are empty on purpose — they
get generated fresh when you run the command above.

FULL PATH (what produced the submission artefacts already in this ZIP)
---------------------------------------------------------------
Command:  python -m src.main --require-research-deps
Time:     Several hours
Folds:    All 19 folds
Output:   results/, figures/, models/
Purpose:  The complete dissertation experiment on the frozen dataset.
          This is what produced the final submission numbers, tables,
          and figures used in the report and demo slides.

You do NOT need to run the full path. The outputs are already in
results/, figures/, and models/. They are included so you can
inspect the full experimental record without waiting hours.

The quick path is the verification path. The full path is the
record of the original experiment.
