SPY Directional Forecasting - 6Z0019 Synoptic Project Creative Piece

Purpose
- This project is a reproducible research pipeline for leakage-safe SPY next-day direction forecasting.
- The easiest examiner path is the quick verification run below.

Supported Python
- Python 3.13
- Verified on Python 3.13.9

Quick examiner verification path
1. Open a terminal inside the dissertation-code folder.
2. Create and activate a virtual environment:
   python -m venv .venv
   source .venv/bin/activate
3. Install examiner dependencies:
   pip install -e ".[dev]"
4. Run the tests:
   pytest tests/
5. Run the quick pipeline:
   python -m src.main --quick

Full dissertation reproduction path
1. Use the same Python 3.13 environment setup above.
2. Install research dependencies:
   pip install -e ".[dev,research]"
3. Run the strict dissertation path:
   python -m src.main --require-research-deps

Expected quick-run evidence
- results/quick/dataset_fingerprint.json
- results/quick/metrics_aggregate.csv
- results/quick/significance_tests.csv
- results/quick/trading_metrics.csv
- figures/quick/walkforward_schematic.png
- figures/quick/metrics_table.png

What the quick run is for
- It uses the bundled frozen dataset data/spy_raw.csv.
- It runs a representative subset of folds for examiner verification.
- It must not overwrite the full submission artifacts in results/, figures/, or models/.

Important notes
- Normal verification should not need to re-download data.
- If xgboost is unavailable, the quick path should still complete with baselines and Random Forest.
- The strict dissertation path uses `--require-research-deps` and fails fast unless both `xgboost` and `shap` are installed.
- If ffmpeg is unavailable, animation export falls back from MP4 to GIF automatically.
- Pickled model files in models/ are included for reproducibility only and should not be treated as trusted external inputs.
