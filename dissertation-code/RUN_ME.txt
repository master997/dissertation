READ INSTRUCTIONS.txt — it has every command you need to run this project.

  source .venv/bin/activate

  python -m pytest tests/ -q
  python -m src.main --quick

Requires Python 3.13. Verified on Python 3.13.9.

After running python -m src.main --quick you will find fresh outputs in:
